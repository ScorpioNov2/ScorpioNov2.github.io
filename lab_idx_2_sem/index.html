📖 Описание

Во втором семестре мы углубляем знания Python и начинаем применять их для создания веб-приложений, сбора данных и анализа. Каждая работа сопровождается теоретическим материалом и практическими заданиями.

✨ Особенности

  • 🌐 Веб-фреймворки Flask и Django
  • 🕷️ Парсинг сайтов с BeautifulSoup и Scrapy
  • 📊 Анализ данных с Pandas и визуализация
  • 🤖 Введение в машинное обучение (scikit-learn)
  • 🐳 Контейнеризация с Docker
  • 🧪 Тестирование и отладка

Индексы

  • 🔹 Лаба 1: Основы Flask – создание простого веб-приложения с маршрутами.
  • 🔹 Лаба 2: Шаблоны и формы в Flask – работа с Jinja2 и обработка форм.
  • 🔹 Лаба 3: Веб-скрапинг с BeautifulSoup – парсинг статических страниц.
  • 🔹 Лаба 4: Парсинг динамических сайтов с Selenium – автоматизация браузера.
  • 🔹 Лаба 5: Знакомство с Django – создание проекта и приложения, модели.
  • 🔹 Лаба 6: REST API на Django REST Framework – разработка API для простого блога.
  • 🔹 Лаба 7: Анализ данных с Pandas – загрузка, очистка и визуализация данных.
  • 🔹 Лаба 8: Введение в машинное обучение (scikit-learn) – классификация и регрессия на простых наборах данных.
  • 🔹 Лаба 9: Docker для Python-приложений – контейнеризация Flask-приложения.
  • 🔹 Лаба 10: Тестирование с pytest – написание юнит-тестов.

🚀 Установка

Требования

  • Python 3.9+
  • pip, virtualenv (рекомендуется)
  • Docker (для лаб 9)

Пошаговая инструкция

1.Клонируйте репозиторий:

git clone https://github.com/ScorpioNov2/PythonLabs.git

2.Перейдите в папку второго семестра:

cd PythonLabs/PythonLabs_year_1th/2_semester

3.Для каждой лабораторной создавайте отдельное виртуальное окружение и устанавливайте зависимости из requirements.txt внутри папки лабораторной (если есть).
