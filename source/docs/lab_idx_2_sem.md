## 📖 Описание

Во втором семестре мы углубляем знания Python и начинаем применять их для создания веб-приложений, сбора данных и анализа. Каждая работа сопровождается теоретическим материалом и практическими заданиями.

## 🚀 Установка

### Требования

- Python 3.9+
- pip, virtualenv (рекомендуется)
- Docker (для лаб 9)

### Пошаговая инструкция

1.Клонируйте репозиторий:
```bash
git clone https://github.com/ScorpioNov2/PythonLabs.git
```  
2.Перейдите в папку второго семестра:
```bash
cd PythonLabs/PythonLabs_year_1th/2_semester
```  
3.Для каждой лабораторной создавайте отдельное виртуальное окружение и устанавливайте зависимости из requirements.txt внутри папки лабораторной (если есть).
